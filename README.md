## About Me

I'm an IT student focused on **cybersecurity**, with hands-on experience across software, mobile, and ML development. I build things to understand how they work, then dig into how they break and how to secure them.

**What I work on**
- Security: reconnaissance, web app security, and vulnerability research
- Machine learning: coursework and applied projects (NumPy, Pandas)
- Full-stack and mobile apps: React Native, Java, web
- Game development in Unity, including experimental EEG-controlled projects

Always up for collaborating on security tooling, CTFs, and open-source projects. Reach me on LinkedIn.
